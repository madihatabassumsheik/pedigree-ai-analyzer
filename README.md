\# AI-Assisted Pedigree Analysis System



A cloud-based web application for pedigree analysis and genetic inheritance prediction using ReactJS, FastAPI, and AWS.



\## Features



\* Interactive pedigree visualization

\* Inheritance pattern prediction

\* Genetic probability calculations

\* AI-generated explanations

\* Synthetic pedigree dataset generation



\## Tech Stack



\* ReactJS

\* FastAPI

\* AWS Amplify

\* AWS Bedrock

\* Python



\## Project Goal



To analyze inheritance patterns and predict genetic risks using AI-assisted pedigree analysis.
